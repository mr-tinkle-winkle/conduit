Archivo, Archivo Black (Omnibus-Type) - Barlow, Barlow Condensed (Jeremy Tribby) - Caveat (Impallari Type)
IBM Plex Mono (IBM) - JetBrains Mono (JetBrains) - Manrope (Mikhail Sharanda) - Oswald (Vernon Adams)
Overpass (Delve Withrington / Red Hat) - Patrick Hand (Patrick Wagesreiter) - Press Start 2P (CodeMan38)
Share Tech Mono (Carrois) - Space Mono (Colophon) - VT323 (Peter Hull)

Archivo, Caveat, JetBrains Mono, Manrope, Oswald and Overpass are static weight
instances generated from the upstream variable fonts with fontTools.varLib.instancer
(Qt only exposes the default instance of a variable font, which left some themes
with a single, often very light, weight). Archivo is instanced at the normal width (wdth 100).
